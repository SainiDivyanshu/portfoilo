CPU Scheduling Simulator

Systems programming · C++

Source

The project where the operating-systems coursework became real code. I implemented four scheduling algorithms — FCFS, Round Robin, Feedback Queues, and Aging — and built the engine around C++ STL structures (priority_queue, vector, queue) to manage arrival order and preemption.
